# Our Little World ♡

A small browser game starring Gelin, with a soft sage-green cottagecore look and pixel-inspired styling.

## Files
- `index.html` — game layout and screens
- `style.css` — colors, room, character styling, responsive layout
- `script.js` — care actions, stats, outfit choices, and cafe date

## Run it
1. Download and unzip `our_little_world.zip`.
2. Open the `our_little_world` folder.
3. Double-click `index.html` to play in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `our-little-world`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then press **Save**.
6. Wait for GitHub to provide your Pages link.

## Current prototype features
- Start screen
- Gelin's cozy bedroom scene
- Happiness, energy, and fullness meters
- Feed, shower, sleep, hug, cheek-kiss, and dance actions
- Four outfit color variations
- Little Fern Café date scene

This is a starter prototype. The character is currently drawn with CSS shapes, not a finished pixel-art sprite sheet. You can replace the character markup/styles with custom pixel sprites as the game grows.
